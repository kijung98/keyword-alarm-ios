키워드알람 개인정보처리방침

시행일: 2026년 10월 12일

요약: 키워드알람은 어떤 개인정보도 수집하거나 외부로 전송하지 않습니다. 모든 데이터는 사용자의 아이폰 안에만 저장되며, 앱을 삭제하면 함께 삭제됩니다.

1. 수집하는 정보

키워드알람(이하 "앱")은 회원가입, 로그인, 서버 전송 기능이 없으며 개발자가 사용자의 정보를 수집하지 않습니다.

2. 기기 안에만 저장되는 정보

  • 설정값: 감시 키워드, 감시 시간대, 내 센터 등
  • 알람 기록: 알람 판정 결과와 문자에서 읽은 요약(금액·날짜·센터·공정). 문자 원문은 저장하지 않습니다.
  • 근무 기록: 사용자가 직접 입력한 근무일, 근무시간, 시급, 메모

위 정보는 아이폰의 앱 전용 저장공간에만 보관되며 개발자나 제3자에게 전송되지 않습니다.

3. 문자 내용 처리 방식

앱은 문자 메시지에 직접 접근하지 않습니다. 사용자가 아이폰 기본 '단축어' 앱에서 직접 만든 자동화가 받은 문자 내용을 앱에 전달하면, 앱은 기기 안에서 키워드 포함 여부만 확인하고 알람을 울립니다. 문자 내용은 판정 직후 버려집니다.

4. 사용하는 권한

  • 알람(AlarmKit): 키워드가 담긴 문자가 왔을 때 무음·집중 모드에서도 알람을 울리기 위해 사용합니다.

5. 제3자 제공 및 추적

앱은 광고, 분석 도구, 추적 기술을 사용하지 않으며 어떤 정보도 제3자에게 제공하지 않습니다.

6. 급여 계산 관련 안내

앱의 급여·주휴수당·공제 금액은 사용자가 입력한 값으로 계산한 추정치이며, 실제 지급액은 사업장의 급여명세서를 기준으로 합니다.

7. 데이터 삭제

앱 안의 '기록 지우기', 근무 기록 삭제 기능으로 언제든 지울 수 있으며, 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.
