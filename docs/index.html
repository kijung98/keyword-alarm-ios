⏰ 키워드알람

중요한 문자가 오면 자는 중에도 크게 깨워 주는 알람 · 근무 기록 앱

처음 설정하기

  1. 앱 홈 탭에서 알람 권한 허용 → 테스트 알람으로 무음 상태에서도 울리는지 확인
  2. 키워드 탭에서 감시할 문구 확인 (예: 인센티브, 특별지급)
  3. 아이폰 단축어 앱 → 자동화 → + → 메시지 → '메시지에 다음 포함'에 키워드 입력 → 즉시 실행
  4. 동작으로 키워드알람 › 문자 확인 후 알람 추가 → '문자 내용'에 단축어 입력 연결
  5. 키워드가 든 문자를 받아 보고, 앱 기록 탭에 '알람 울림'이 남으면 완료

자주 묻는 질문

알람이 안 울려요.

앱 기록 탭을 확인하세요. 기록이 없으면 단축어 자동화가 '즉시 실행'으로 설정됐는지, '감시 시간 아님'이면 홈 탭의 감시 시간대를 확인하세요.

카카오톡 메시지도 감지되나요?

아이폰에서는 다른 앱의 알림을 읽을 수 없어 문자 메시지만 지원합니다.

문자 내용이 어딘가로 전송되나요?

아니요. 모든 판정은 아이폰 안에서만 이루어지며 문자 원문은 저장하지 않습니다.

급여 금액이 실제와 달라요.

앱의 금액은 입력값 기준 추정치입니다. 근무 입력에서 '일급을 직접 입력'을 켜고 실제 일급을 넣으면 더 정확해집니다.
