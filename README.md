# 키워드알람 (KeywordAlarm) — iOS

특정 문구가 담긴 **문자**가 오면 **무음·집중 모드에서도 시계 앱처럼 크게 울리는** 아이폰 앱입니다.
야간 근무 후 낮에 자는 사람이 "추가지급", "긴급 호출" 같은 문자를 놓치지 않도록 만들었습니다.

- 최소 버전: **iOS 26** (AlarmKit 사용)
- 개발 도구: **Xcode 26 이상** (Mac 필요)
- 개인정보: 문자 전문은 저장·전송하지 않음. 판정 결과와 일치 키워드만 기기에 기록

---

## 동작 구조

```
문자 도착
  ↓  아이폰 '단축어' 자동화 (메시지 수신 시, 즉시 실행)
  ↓  키워드알람 › 문자 확인 후 알람 (문자 내용 = 단축어 입력)
  ↓  키워드 · 시간대 · 요일 · 중복방지 판정
  ↓  AlarmKit 알람 예약 (2초 뒤) → 무음/집중 모드를 뚫고 울림
```

아이폰은 앱이 문자를 직접 읽을 수 없으므로, 문자 감지는 단축어가 맡고 이 앱은 **판정 + 알람**을 맡습니다.

## 1단계. Mac에서 빌드하기

### 방법 A — XcodeGen (추천, 5분)
```bash
brew install xcodegen
cd KeywordAlarm
xcodegen generate
open KeywordAlarm.xcodeproj
```

### 방법 B — Xcode에서 직접
1. Xcode › New Project › iOS App (이름 `KeywordAlarm`, Interface: SwiftUI, Language: Swift)
2. 자동 생성된 `ContentView.swift`, `KeywordAlarmApp.swift` 삭제
3. 이 저장소의 `KeywordAlarm/` 폴더 안 파일들을 프로젝트로 드래그 (Copy items 체크)
4. Target › General › Minimum Deployments: **iOS 26.0**
5. Target › Info 탭에 키 추가: `NSAlarmKitUsageDescription` = `등록한 키워드가 담긴 문자가 오면 무음 모드에서도 알람을 울리기 위해 사용합니다.`

### 공통
- Target › Signing & Capabilities › Team에서 본인 Apple 개발자 팀 선택
- Bundle Identifier가 겹치면 `com.본인아이디.keywordalarm` 으로 변경
- 아이폰 연결 후 ▶ 실행 (AlarmKit은 **실기기**에서 테스트 권장)

## 2단계. 아이폰에서 설정

1. 앱 실행 → 홈 탭 **알람 권한 허용** → **테스트 알람(5초 뒤)** → 무음 모드로 화면 끄고 울리는지 확인
2. 키워드 탭에서 키워드 확인 (기본값: `인센티브`, `특별지급`, `추가지급 혜택`), 문구 테스트 칸에 실제 문자를 붙여 넣어 판정 확인
3. **단축어 앱 › 자동화 › + › 메시지**
   - 자동화 ①: 메시지에 다음 포함 `인센티브` (인천 14·28·26·36센터 형식)
   - 자동화 ②: 메시지에 다음 포함 `특별지급` (인천 17·39 신선센터 형식)
   - 두 자동화 모두 아래 4~5단계를 똑같이 설정
   - **즉시 실행** 선택 (실행 전 확인 ❌)
4. 새로운 빈 단축어 › 동작 검색 `키워드알람` › **문자 확인 후 알람**
5. '문자 내용' 칸 → **단축어 입력** 선택 → 완료
6. 다른 폰에서 키워드가 든 문자 전송 → 앱 **기록 탭**에 `알람 울림`이 남으면 성공

## 검증 체크리스트 (PoC)

- [ ] 무음 스위치 ON + 화면 꺼짐 상태에서 테스트 알람이 울린다
- [ ] 집중 모드(수면) 중에도 울린다
- [ ] 실제 문자 수신 → 단축어 자동화 → 알람까지 이어진다 (**핵심 확인 항목**)
- [ ] 시간대 밖 문자는 기록에 '감시 시간 아님'으로 남고 울리지 않는다
- [ ] 같은 문자가 연달아 와도 중복 방지 시간 동안 한 번만 울린다

## 확인이 필요한 부분 (확실하지 않음)

- 단축어 자동화에서 백그라운드로 실행된 동작이 AlarmKit 알람을 바로 예약할 수 있는지는 **실기기 검증 필요** (위 체크리스트 3번)
  - 안 될 경우 대안: `CheckMessageIntent`의 `openAppWhenRun`을 `true`로 바꿔 앱을 깨운 뒤 예약
- AlarmKit API는 iOS 26.x 업데이트에서 일부 인자 이름이 바뀔 수 있음 → 빌드 경고/오류가 나면 Xcode 자동 수정 제안을 따르거나 오류 문구를 공유해 주세요
- 이 코드는 리눅스 환경에서 작성되어 **아직 Xcode로 컴파일되지 않았습니다**. 첫 빌드에서 작은 수정이 필요할 수 있습니다

## 알람 화면에 보이는 정보

문자에서 아래 항목을 자동으로 읽어 **알람 제목 한 줄**로 보여 줍니다.

```
💰+30,000원 · 오늘 오후조 18:00 외 1 · 인천14 · HUB
```

| 항목 | 읽는 위치 | 표시 |
|---|---|---|
| 추가지급 금액 | `추가지급 혜택 : 일급 + 30,000` | +30,000원 |
| 적용일자·근무조 | `적용일자 및 근무조 : 2026-10-11 (일) 오후조 18:00~04:00, …` | 오늘 / 내일 / 모레 / 어제 + 근무조 |
| 대상센터 | `대상센터 : 인천 14센터` | 인천14 (내 센터가 아니면 앞에 ⚠️다른센터) |
| 대상공정 | `대상공정 : 허브(HUB)` | HUB |
| 지원 링크 | `셀프스케줄링 접수` 다음 줄 링크 | 상세 화면의 '지원 페이지 열기' 버튼 |

- 알람의 **'자세히'** 버튼 → 앱이 열리며 금액·날짜·센터·공정을 큰 글씨로 보여 주는 상세 화면 표시
- **내 센터** 등록: 홈 탭에서 센터 추가 → 알람·상세 화면에 '내 센터 / 다른 센터' 표시
  - '내 센터 문자만 알람'을 켜면 다른 센터 인센티브는 울리지 않고 기록에만 남음
- **지난 날짜** 문자는 기본적으로 울리지 않음 (날짜를 못 읽으면 안전하게 울림)
- **중복 방지**는 같은 내용(센터·날짜·금액)일 때만 적용 → 다른 센터 인센티브는 바로 울림
- 문자 원문은 저장하지 않고 위 요약 정보만 기기에 저장

> 확실하지 않음: 잠금화면 알람 제목이 몇 글자까지 보이는지는 기기에서 확인 필요. 잘리면 금액·날짜가 먼저 보이도록 중요한 순서로 배치했습니다.

## 지원하는 문자 형식 (실제 문자로 검증)

| 센터 | 잡히는 키워드 | 날짜 | 근무조·시간 | 금액 |
|---|---|---|---|---|
| 인천 14 | 인센티브, 추가지급 혜택 | `적용일자 및 근무조 : 2026-10-11 …` | 같은 줄 | `추가지급 혜택 : 일급 + 30,000` |
| 인천 28·26·36 | 인센티브 | `#대상일자 : 2026년 10월 11일` | `오후 : …` 급여줄 + `18~04시, 21~06시` | `#추가 지급금액 : 30000원` + 근무조별 총액 |
| 인천 17·39 신선 | 특별지급 | `10월 11일(일) 바로 내일` | `▶주간1(08:00~17:00)` | 센터·근무조·공정별 금액표 (+30,000~45,000원) |
| 일반 모집 문자 | 없음 → 안 울림 ✅ | | | |

- 금액이 여러 개면 알람에 **최대 금액**, 내 센터를 등록했으면 **내 센터 최대 금액**을 표시
- 여러 센터 묶음 문자(28·26·36)는 그중 하나라도 내 센터면 '내 센터'로 판단
- ★로 강조된 주의사항(예: "심야조는 28센터만 운영 중입니다")은 상세 화면에 주황색 경고로 표시
- 새 형식의 문자가 오면 `KeywordAlarmTests/RealMessages.swift`에 추가하고 테스트를 늘리는 방식으로 보강

## 근무 기록 · 급여 계산 (근무 탭)

| 기능 | 내용 |
|---|---|
| 달력 | 날짜를 눌러 근무 입력, 칸마다 그날 수입(예: 12.6만) 표시 |
| 근무 입력 | 센터·근무조·출퇴근·휴게·시급·추가 연장·야간 가산·인센티브·메모 |
| 인센티브 불러오기 | 그날 받은 인센티브 문자에서 센터·근무조·시간·금액 자동 입력 |
| 일급 직접 입력 | 문자에 나온 일급(예: 125,280원)을 그대로 사용 |
| 이번 주 진행 | 일~토 기준 ●●●○○, "1일 더 일하면 주휴수당 +82,560원" |
| 축하 애니메이션 | 주 5일(설정 가능) 달성 순간 색종이 + 주휴수당 금액 + 진동 |
| 월간 요약 | 세전 합계, 근무일수, 시간, 예상 실수령, 지난달 대비, 목표 달성률 |
| 체크포인트 | 4대보험 기준(월 8일)까지 남은 일수, '월 15일 근무 보너스' 같은 사용자 규칙 진행률 |

### 계산 규칙 (2026년, 모두 추정치)
- 최저임금 10,320원 / 8시간 초과·추가 연장 1.5배 / 22~06시 야간 0.5배 가산
- 주휴수당 = (주 근무시간 ÷ 40, 최대 1) × 8 × 시급
  - 법 기준: 주 15시간 이상 (근로기준법)
  - 회사 기준: 주 5일 (쿠팡 공지 '일~토 기준 주 5일'. 고용노동부가 2025년 11월 개선 명령) → 설정에서 선택
- 공제: 고용보험 0.9% / 월 8일 또는 60시간 이상이면 국민연금 4.75%·건강보험 3.595%·장기요양(건강보험료의 13.14%)
- 일용근로소득세: (일급 − 150,000원) × 2.7%, 1,000원 미만 면제 / 지방소득세 10%
- 실제 지급액·가입 여부는 급여명세서와 4대사회보험 정보연계센터(4insure.or.kr)에서 확인
